# 🚀 Featured Projects

## 💸 Financeel

**Personal finance platform designed to make money management simple and visual.**

🌐 **financeel.net**

Financeel started as a personal project and evolved into a complete web application with authentication, subscriptions, financial tracking and automation.

### Features

- 📊 Financial dashboard & analytics
- 💰 Income and expense tracking
- 🎯 Savings plans
- 📅 Financial calendar
- 🔮 Financial projections
- 🧮 Financial calculators
- 🤖 Telegram bot integration
- 📱 Siri Shortcuts integration
- 💳 Stripe subscriptions
- ✉️ Automated email workflows
- 📂 Financial data import tools

**Stack:** TypeScript · React · PostgreSQL · Stripe · Railway · APIs · Telegram
